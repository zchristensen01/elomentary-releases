A pre-game scouting report for League of Legends, for whichever role you're playing. While you
draft, Elomentary suggests picks from your own champions. At the loading screen it shows one
short report: how your lane goes, whether you got counter-picked and how to play into it, what
both junglers mean for you, who must not get fed, and a game plan.

It only **reads** your League client (it never clicks, picks or changes anything) and it shows
nothing during the game. Windows 10 or 11.

## Download

**[Download ElomentarySetup.exe](https://github.com/zchristensen01/elomentary-releases/releases/latest/download/ElomentarySetup.exe)**
(about 40 MB). That link is always the newest version.

1. If your browser says the file **isn't commonly downloaded**, choose **Keep**.
2. Open it. If Windows shows **"Windows protected your PC"**, click **More info**, then
   **Run anyway**. You only see this the first time: the app is free and not code-signed.
3. Click **Install**, then **Finish**.

Elomentary updates itself after that. To remove it: Windows **Settings** → **Apps** →
**Installed apps** → **Elomentary** → **Uninstall**.

This repository only holds the downloads. Each release lists its installer's SHA-256.
